## CSV와 문서 수가 다른 이유

일부 폴더에는 CSV 행 외에 템플릿·빈 페이지가 함께 있습니다. 전체 CSV는 총 1500행이며 ZIP에는 Markdown 1667개가 있습니다. 일반 페이지·데이터 소스·템플릿을 같은 이벤트 수로 더하지 않습니다. CSV에는 원본 ID 열이 없어 제목·폴더 구조를 함께 대조했습니다.

한 건은 CSV 제목이 비어 있으나 폴더에는 ‘0. 이벤트이름’ 템플릿이 있어 ID 일대일 연결을 확정하지 않았습니다. 해당 [전체 CSV](export-tables/6ef0221954bc83988cbd012b63e1c614.csv)와 폴더의 모든 문서를 보존했습니다. 삭제·추정 ID 생성으로 숨기지 않았습니다.

## ZIP 파일 보존 범위

전체 목록 CSV 41개뿐 아니라 보기별 CSV 39개도 [CSV 대응표](zip-csv-map.json)에 따라 저장했습니다. Markdown 1,667개 + CSV 80개 + 이미지 1,473개 = ZIP 내 파일 3,220개 모두에 저장소 대응이 있습니다. 이미지 파일 수는 내용 중복 때문에 저장소의 1,472개와 다를 수 있으며 해시로 대조했습니다.

검증: 주요 필드 11,314개·이미지 참조 3,354개 대조에서 누락 0개, Notion 외부 URL·미지원 이미지 태그 0개. 기존 이미지 1,472개는 GitHub blob SHA까지 일치했습니다. 로컬 테스트 18개와 생성물 일치 검사를 통과했습니다. 모든 UI의 육안 검수나 앱 동작 검증 완료를 뜻하지 않습니다.
