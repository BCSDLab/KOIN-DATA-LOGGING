### 쿼리

```sql
WITH first_event_per_user AS (
  SELECT
    user_pseudo_id,
    ARRAY_AGG(
      device.language IGNORE NULLS
      ORDER BY event_timestamp
      LIMIT 1
    )[SAFE_OFFSET(0)] AS first_language
  FROM `kap-chat.analytics_432041405.events_*`
  WHERE _TABLE_SUFFIX BETWEEN '20260927' AND '20261026'
    AND user_pseudo_id IS NOT NULL
  GROUP BY user_pseudo_id
),
classified AS (
  SELECT
    user_pseudo_id,
    first_language,
    LOWER(
      SPLIT(REPLACE(first_language, '_', '-'), '-')[SAFE_OFFSET(0)]
    ) AS language_base
  FROM first_event_per_user
)
SELECT
  COUNT(*) AS total_users,
  COUNTIF(language_base = 'ko') AS korean_language_users,
  COUNTIF(
    language_base IS NOT NULL AND language_base != 'ko'
  ) AS foreign_language_users,
  COUNTIF(language_base IS NULL) AS unknown_language_users,
  ROUND(
    100 * SAFE_DIVIDE(
      COUNTIF(language_base IS NOT NULL AND language_base != 'ko'),
      COUNTIF(language_base IS NOT NULL)
    ),
    2
  ) AS foreign_share_pct_among_known
FROM classified;
```

```sql
WITH first_new_event AS (
  SELECT
    user_pseudo_id,
    ARRAY_AGG(
      STRUCT(
        device.language AS language,
        event_name,
        event_timestamp
      )
      ORDER BY event_timestamp
      LIMIT 1
    )[OFFSET(0)] AS first_event
  FROM `kap-chat.analytics_432041405.events_*`
  WHERE _TABLE_SUFFIX BETWEEN '20260927' AND '20261026'
    AND user_pseudo_id IS NOT NULL
    AND event_name IN ('first_visit', 'first_open')
  GROUP BY user_pseudo_id
),
classified AS (
  SELECT
    user_pseudo_id,
    first_event.event_name AS acquisition_event,
    first_event.language AS first_language,
    LOWER(
      SPLIT(REPLACE(first_event.language, '_', '-'), '-')[SAFE_OFFSET(0)]
    ) AS language_base
  FROM first_new_event
)
SELECT
  COUNT(*) AS new_users,
  COUNTIF(language_base = 'ko') AS korean_language_new_users,
  COUNTIF(
    language_base IS NOT NULL AND language_base != 'ko'
  ) AS foreign_language_new_users,
  COUNTIF(language_base IS NULL) AS unknown_language_new_users,
  ROUND(
    100 * SAFE_DIVIDE(
      COUNTIF(language_base IS NOT NULL AND language_base != 'ko'),
      COUNTIF(language_base IS NOT NULL)
    ),
    2
  ) AS foreign_share_pct_among_known
FROM classified;
```

## 3. 해석과 주의사항

1. 전체 활동 사용자와 신규 유입 사용자의 분모가 다르므로 두 비율을 섞어 쓰지 않는다.
2. 서비스 국제화 수요를 판단할 때는 신규 유입 기준 <b>13.07%</b>를 우선 참고하고, 현재 활성 기반 영향도를 볼 때는 전체 활동 기준 <b>8.34%</b>를 참고할 수 있다.
3. <code>device.language</code>는 국적·거주지·사용자의 선호 언어를 확정하는 값이 아니다.
4. 기간 중 언어를 변경한 사용자는 기준 이벤트 하나의 언어로만 분류된다.
5. 운영 지표로 사용하려면 기간을 동적으로 받고 일·주·월 추이를 함께 모니터링하는 쿼리 또는 Gold 지표 설계가 추가로 필요하다.
6. 이번 조사는 Production 원본을 읽기 전용으로 조회했으며 Silver 또는 Gold 객체를 수정하지 않았다.
