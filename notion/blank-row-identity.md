# 제목 없는 CSV 행의 원본 ID 확인

대상: [홈화면 리디자인 / 버스 로깅 (3)](pages/6ef0221954bc83988cbd012b63e1c614.md)의 [전체 CSV](export-tables/6ef0221954bc83988cbd012b63e1c614.csv) 첫 번째 데이터 행(헤더 포함 2행).

**원본 ID: `f4b0221954bc822c9b7b81490f4a78bd` — [0. 이벤트이름](pages/f4b0221954bc822c9b7b81490f4a78bd.md) 데이터베이스 템플릿으로 확인했습니다.** 신규 로그 이벤트나 새 원본 페이지를 추가한 것이 아닙니다.

## 확인 근거

1. DB의 **2026-11-12 14:07:59 KST** 버전에서 유일한 템플릿이 ‘제목 없음’이며 이 ID로 등록되어 있습니다.
2. ZIP 다운로드 시각 근처인 **2026-11-12 19:25:06 KST** DB 버전에서도 같은 ID가 ‘0. 이벤트이름’으로 등록되어 있습니다. 템플릿 이름이 달라도 ID는 동일합니다.
3. 제목 있는 CSV 27개 행은 제목·상태·구분·플랫폼으로 현재 무필터 일반 행 27개와 각각 단일 대응합니다. ZIP의 같은 폴더 Markdown 28개에서 이 27개 ID를 제외하면 해당 템플릿 ID 하나만 남습니다.
4. 템플릿 본문은 example 라벨·example 값·click 카테고리의 작성 양식입니다. 생성 계약으로 승인하거나 운영 이벤트 개수에 더하지 않습니다.

## 원문 차이 보존

CSV의 제목은 비어 있고 생성일은 ‘2026년 11월 12일 오후 2:07’, Markdown 제목은 ‘0. 이벤트이름’이며 생성일은 오후 2:08입니다. **생성일 불일치의 원인은 확정하지 않았습니다.** 원본 ID는 생성일을 임의로 맞춘 결과가 아니라, DB 템플릿 등록 이력과 같은 폴더의 문서 대조로 확인했습니다.

CSV·ZIP 원문 스냅샷·해당 Markdown 본문을 수정하지 않고 그대로 보존했습니다. [기계 판독 근거와 행별 대응표](blank-row-identity.json)에 식별 근거 및 차이를 기록했습니다.

이전 미확정 CSV 행 1건은 ID 대응이 해결됐습니다. 원문의 제목·생성일 표현 차이는 기록으로 유지합니다. 제공된 ZIP 밖의 페이지, 전체 라이브 워크스페이스, UI 육안 검수나 앱 적용 완료를 뜻하지 않습니다.
