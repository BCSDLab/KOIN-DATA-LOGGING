## 조회 불가 링크 제거

2026-11-27 사용자 요청으로 조회되지 않는 참고 링크 4개를 Notion Event Log·문서 이력과 이 PR의 현행 안내에서 제거했습니다. 연결 대상 페이지 자체를 삭제하거나 복구한 것은 아닙니다. 대체 문서가 확인되지 않은 프론트엔드 파이프라인 참조는 안내에서 제외했습니다.

과거 GitHub 커밋과 원문 보존본은 당시 기록으로 유지합니다. 링크 제거를 근거로 조회하지 못한 원문의 내용 일치나 모든 참고문서의 완전 복제를 주장하지 않습니다.

사용자 요청으로 이전 게시판 빈 페이지 1개에 이어 기존 목록의 빈 항목 22개도 다시 조회해 본문이 비어 있음을 확인하고 Notion 휴지통으로 이동했습니다. 제목 없는 18개와 제목이 있는 결제 관련 자리표시자 4개이며, GitHub 현행 서비스 목록의 22개 링크도 제거했습니다. 내용이 있는 명세 785개와 이미지는 유지합니다. [삭제 기록](removed-blank-pages.json)과 최초 스냅샷은 당시 상태를 보존합니다. Notion 휴지통에서 복원할 수 있습니다.
