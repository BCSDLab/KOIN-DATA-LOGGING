## 확정 사항

2026-11-12 사용자가 '강제 업데이트는 da1으로 해줘'라고 확정했습니다. 상위 문서 DA2와 상세 페이지 DA1의 충돌은 이 저장소에서 **main/forced_update → DA1** 예외로 해소했습니다. 노션 원문은 수정하지 않았습니다. main의 다른 화면은 기존 DA2를 유지합니다.

강제 업데이트 상세 5페이지의 새 label·value·발생 조건을 보존했습니다. 초기 생성 대상은 ANDROID만 등록했습니다. IOS·WEB·WEB (모바일)은 platform_support에서 unknown(지원 미확인)으로 기록하며 생성 대상에서 제외합니다. 지원 근거를 확인한 뒤 담당자가 platform_support를 confirmed로 변경하고 platforms를 명시적으로 확장해야 합니다. Android의 실제 프로젝트 컴파일·SDK 적용·배포·실수집 검증은 별도 후속 작업입니다.

카테고리는 현행 네이밍 확정본에 명시된 모바일 WEB 4개만 가져왔습니다. 가이드에서 링크한 개별 카테고리 페이지 두 개는 조회 결과 deleted로 표시되어 운영의 단일 출처로 채택하지 않았습니다. 나머지 9개 메뉴와 플랫폼 합집합은 자동 이관하지 않았습니다.

| 과거 label | 과거 의미·주의 |
