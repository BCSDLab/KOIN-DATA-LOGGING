# KOIN Event Log

개발자를 위한 서비스별 로깅 명세입니다. **서비스 → 로깅 목록 → 개별 명세** 순서로 열면 `event_name`, `event_label`, 설명·값·카테고리와 이미지를 한 페이지에서 확인할 수 있습니다.

과거 로깅에는 예전 정의와 예전 이미지, 새 로깅에는 새 정의와 해당 이미지가 원문 구간대로 함께 표시됩니다. 원문에 구분이 없거나 항목이 없으면 추정하지 않고 표시합니다.
