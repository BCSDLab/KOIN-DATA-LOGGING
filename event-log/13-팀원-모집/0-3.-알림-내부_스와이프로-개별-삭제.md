- 설명: 팀원 모집 전용 알림 항목을 스와이프하는 제스처 자체가 개별 삭제 실행으로 확정되는 UI에서, 삭제 임계점을 넘어 삭제 동작이 확정될 때 1회 기록한다. 취소된 스와이프·원위치 복귀·삭제 버튼 노출만으로는 기록하지 않는다.
