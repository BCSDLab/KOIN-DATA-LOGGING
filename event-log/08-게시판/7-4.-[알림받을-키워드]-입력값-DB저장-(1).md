# 7-4. [알림받을 키워드] 입력값 >> DB저장 (1)

[← 게시판 로깅 목록](README.md)

플랫폼: ANDROID · IOS  
원문 상태: 레거시

과거 로깅·새 로깅과 각 참고사진은 원문의 구간별 연결을 유지합니다.

원문 미기재 항목: `screen_view`. 값을 추정하지 않았습니다.



<!-- logging-section:past:start -->
## 과거 로깅


로그인되었을 경우 백엔드 db에 저장하고 로그인이 안되어있다면 클라이언트 서버에 저장


<!-- logging-section:past:end -->


<!-- logging-section:new:start -->
## 새 로깅


- 설명: 입력한 알림 키워드의 저장 완료를 구분하기 위한 초안.
- screen\_view:
- event\_name: <code>DA2</code>
- event\_label: <code>board__notice_keyword_manage__keyword__save</code>
- value: “키워드 저장 완료”
- event\_category: <code>success</code>
- 적용 플랫폼: ANDROID, IOS
- 참고사항
  - 로그인 시 백엔드 DB에 저장하고 비로그인 시 클라이언트 서버에 저장한다는 기존 지시를 보존합니다. 비로그인 저장 위치와 성공 판정 기준은 구현 확인이 필요합니다.
  - 위 event\_name/event\_label은 저장 완료 분석 이벤트의 후보입니다. 분석 이벤트 전송 여부는 별도로 확정합니다.
  - 분석 이벤트의 value는 키워드 저장 완료로 두고, 원문 키워드의 내부 저장 요구사항은 별도로 유지합니다.
