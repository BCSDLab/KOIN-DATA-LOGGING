### 플랫폼별 계약 범위

2026-11-27 사용자 확정: <b>swipe는 IOS 전용</b>이다. Android·Web의 기존 swipe 수집은 지원 범위 밖 전송으로 검수하며, 과거 기록을 개명하거나 click으로 자동 치환하지 않는다. 아래 표는 이 페이지의 개별 계약 범위이며 페이지 platform 속성은 확정된 범위의 합집합이다. 문서 수정은 SDK 배포·실수집 정상 완료를 뜻하지 않는다.

| event\_label | platform |
| --- | --- |
| <code>callvan__callvan_notification__notification_list__delete__click</code> | 미확정 |
| <code>callvan__callvan_notification__notification_list__delete__swipe</code> | IOS |

## 새 로깅 (26.11.11)

- 설명: 콜밴팟 전용 알림 목록에서 사용자가 개별 알림의 삭제 버튼을 누를 때 1회 기록한다.
- screen\_view: <code>callvan_notification</code>
- event\_name: <code>DA2</code>
- event\_label: <code>callvan__callvan_notification__notification_list__delete__click</code> /  <code>callvan__callvan_notification__notification_list__delete__swipe</code>
- value: 알림 삭제
- event\_category: <code>click</code> / <code>swipe</code>

## 검토사항

- 지원 검토 중. 확인한 WEB 팀원 모집 NotificationCard에는 개별 삭제 버튼이 없다. ANDROID·IOS의 전용 알림함에 같은 동작이 있는지 확인 후 해당 플랫폼에만 적용한다. 버튼이 없는 플랫폼에 새 버튼 구현을 요구하는 명세가 아니다.
- [WEB 화면 코드](https://github.com/BCSDLab/KOIN_WEB_RECODE/blob/9b6b7a2a29e70f59409bb1136cf2ec7bb9765ab6/src/pages/team/notifications/index.tsx) · [상단 메뉴 코드](https://github.com/BCSDLab/KOIN_WEB_RECODE/blob/9b6b7a2a29e70f59409bb1136cf2ec7bb9765ab6/src/components/Team/components/TeamNotificationHeader/index.tsx)
- 문서·기능 코드 대조이며 배포·단일 전송·실수집 완료는 미확인이다. Silver·Gold 매핑과 데이터는 이번 작업에서 변경하지 않는다.
- 기존 원문: [1-2 알림 클릭 내부](https://app.notion.com/p/4010221954bc82a9b0b7819eafa98396)
