# 3-1 상점 카테고리 → 상점상세 (클릭)

[← 새 주변상점 - 레거시 로깅 목록](README.md)

플랫폼: ANDROID · IOS · WEB  
원문 상태: 완료

원문에 과거·새 로깅 구분이 없어 아래 정의와 참고사진을 원문 순서로 표시합니다.

원문 미기재 항목: `event_name`, `screen_view`. 값을 추정하지 않았습니다.

event\_params.key


- event\_label : shop\_click


- value : \{상점이름\} 


- event\_category : click 


- previous\_page : \{카테고리\}


- current\_page : \{상점이름\}


- duration\_time : 상점 카테고리에서 상점상세 페이지로 들어간 시간(ms) 


---


상점카테고리에서 상점 상세 페이지로 들어가는 시간을 파악하고자 합니다.
