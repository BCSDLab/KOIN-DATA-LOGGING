원문 상태: 로깅 필요

원문에 과거·새 로깅 구분이 없어 아래 정의와 참고사진을 원문 순서로 표시합니다.

원문 미기재 항목: `event_name`, `screen_view`, `event_category`. 값을 추정하지 않았습니다.

event\_params.key


- event\_label : shop\_detail\_view


- value : \{상점이름\} 


- event\_category : 

- scroll
- click
