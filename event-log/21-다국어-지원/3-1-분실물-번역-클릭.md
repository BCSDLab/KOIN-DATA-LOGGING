## 새 로깅 (26.11.16)

- 설명: 분실물 게시글 상세 화면에서 활성화된 번역 버튼을 클릭해 해당 게시글의 번역 요청을 시작할 때 1회 기록한다.
- screen\_view: <code>lost_item_detail</code>
- event\_name: <code>DA1</code>
- event\_label: <code>board__lost_item_detail__translation__request__click</code>
- value: 번역
- event\_category: <code>click</code>


### 참고사진 (분실물 번역 버튼)

<b>앱</b>

앱 — 사용자 제공 앱 디자인에 빨간 네모를 표시한 참고사진이다. iOS·Android 각각의 SDK 구현·배포·실수집 검증은 미확인이다.
