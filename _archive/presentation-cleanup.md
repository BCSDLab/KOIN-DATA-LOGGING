# 명세 표시 형식 정리

사진이 없는 구간의 빈 제목을 없애고, 이미지가 있는 플랫폼만 하위 제목으로 표시합니다. 필요한 미확보 사유와 기존 사진 참조는 유지합니다.

- 열람 문서 697개 표시 형식 보완. 이 중 322개는 기존 서비스 이름·제목·원문 상태에 따라 제목의 **[레거시]**와 상단 안내를 추가했습니다.
- 레거시 서비스 5개 목록에 안내를 넣고, 현행 서비스 목록 안의 레거시 명세에도 **레거시**를 표시했습니다.
- 사진 앞의 단독 반복 라벨 279개, 중복 플랫폼 라벨 612개, 사진 없는 제목·빈 안내 364개를 정리했습니다.
- 과거 사진을 참조하는 7곳은 같은 페이지의 과거 로깅으로 이동하는 링크로 바꿨습니다.
- 원문 미확보 사유·플랫폼 차이·전환 초안·강제 업데이트 이탈 미확정 설명은 보존했습니다.

755개 문서의 주요 필드, 과거·새 구간 768개, 이미지 참조 1,551개와 원본 이미지 1,227개의 해시를 기존 Notion 스냅샷에 대조합니다. 기존 보존 원문 3,308개와 보관 이미지 1,472개는 수정하지 않습니다. 이번 작업에서 Notion을 다시 조회하거나 수정하지 않았습니다.

변경 전·후 Git blob SHA와 대표 문서의 본문 SHA는 [표시 변경 기록](presentation-cleanup.json)에 남깁니다. 목록 대표·추가 원본 관계 검사는 이 기록에 포함된 형식 변경만 허용하고, 기존 Notion 정의·이미지 대조 검사는 계속 실행합니다.
