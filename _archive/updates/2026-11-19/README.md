## 검토 필요

- 복덕방 사진 넘기기: 원본 platform은 WEB, 본문에는 모바일 swipe가 있습니다. 속성과 본문을 원문대로 두고 지원을 미확정으로 표시했습니다.
- 시간표 학기 추가·삭제: ZIP은 모바일 value가 연도_학기입니다. GitHub에만 있던 추가/삭제 접두어와 묶음 전송 규칙은 before에 보존했습니다. 구현에 적용하기 전 담당자 확인이 필요합니다.
- 뒤로가기 click·swipe는 별도 페이지로 유지합니다. room_common 및 라벨의 마지막 click/swipe 차이를 유지합니다. 스와이프는 IOS만 명시하며 지원 완료로 간주하지 않습니다.
- 과거 Event Log 전체 복제 트리·빈 제목·작성 템플릿은 이번 현행 이전 대상이 아닙니다. 다른 서비스의 과거 문구·취소선 차이와 이미지 구간 표식 차이를 일괄 수정하지 않았습니다.
